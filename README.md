# CampusCare AI

A responsive campus support platform built for Hack Devengers 1.0.

## Features
- Student login
- Dashboard
- Announcements
- Lost & Found
- Complaint management
- Emergency Hub
- CampusCare AI assistant
- SQLite database
- Responsive Bootstrap UI

## Run locally

### 1. Install Python
Python 3.10+ recommended.

### 2. Open terminal in this folder

```bash
pip install -r requirements.txt
```

### 3. Start the app

```bash
python app.py
```

### 4. Open

http://127.0.0.1:5000

## Demo login
Use any name and email.

## Important
The emergency numbers in this demo are placeholders except 112. Replace them with your institution's verified contacts before public deployment.
